# Advanced Student Management System

## Extended Description
This is a comprehensive Student Management System web application that allows users to manage student records with full CRUD operations.  
Built using HTML, CSS, and JavaScript, this project demonstrates the ability to develop real-world web applications with dynamic behavior and persistent storage using localStorage.

### Key Functionalities:
- Add, edit, and delete student records with validation to prevent duplicate roll numbers
- Search students quickly by name or roll number
- Display total number of students dynamically
- Clear all records with a single click
- Responsive and clean user interface for better user experience

This project showcases my skills in:
- DOM manipulation
- Frontend logic and data management
- Creating user-friendly web interfaces
- Problem-solving through validation and dynamic updates

It is an internship-ready project that reflects practical web development skills, suitable for frontend development roles.
